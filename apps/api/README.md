# @nora/api

NestJS 12 API for Nora. See the [root README](../../README.md) for setup.

| Command | What it does |
| --- | --- |
| `pnpm dev` | Generate the Prisma client and start the API in watch mode on port 4000 |
| `pnpm test` | Unit and orchestration tests (Vitest) |
| `pnpm db:migrate` / `pnpm db:seed` | Apply migrations / load synthetic demo data |
| `pnpm typecheck` / `pnpm lint` | TypeScript and Oxlint |
